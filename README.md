1. Откройте страницу настроек расширения (кнопка в шапке сайта FunPay или через иконку расширения).
2. Перейдите во вкладку **«API»**.
3. Заполните три основных параметра:
   - **Base URL** — базовый адрес API эндпоинта (например, `https://api.deepseek.com/v1`).

   - **Model** — название модели (например, `deepseek-chat` или `gpt-4o-mini`).
4. Нажмите **«Сохранить настройки»**, а затем **«Проверить подключение»** для верификации соединения.

## 📦 Установка в браузер (Chrome, Edge, Яндекс.Браузер, Opera)

1. Скачайте проект как ZIP-архив (кнопка **Code** -> **Download ZIP**) и распакуйте в любую удобную папку (или клонируйте репозиторий через `git clone`).
2. Откройте в браузере страницу расширений:
   - В Chrome: `chrome://extensions/`
   - В Edge: `edge://extensions/`
   - В Яндекс.Браузере / Opera: `browser://extensions/`
3. В правом верхнем углу включите переключатель **«Режим разработчика»** (Developer mode).
4. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked) в левом верхнем углу.
5. Выберите папку с распакованными файлами проекта.
6. Перейдите на [FunPay](https://funpay.com) и пользуйтесь!
